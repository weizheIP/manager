# M1 导航骨架检查记录

日期：2026-09-20。分支：`feat/m1-navigation`。

此文件是导航骨架阶段的历史检查记录；后续实现与验证见 [本地任务与提醒记录](M2_本地任务与提醒验收.md)。以下“未实现”描述只适用于当时的提交。

## 本次范围

以 SwiftUI 实现总览、任务栏、日历、人员和中央添加入口。底栏独立于内容滚动区域；“＋”通过 sheet 展示创建卡片，不改变所选页面。暮山紫有浅色/深色版本，装饰山形用 Canvas 绘制，不依赖外部图片或网络。

总览按“每日道德经区域 → 今日重点 → 四象限 → 即将到期 → 最近任务栏”排列。道德经仅保留内容位置，没有生成或伪造原文。任务栏、人员、日历均为预览页；月/周视图、任务保存、负责人和 DDL 业务不在本次实现范围。

保留前序已配置的 App 显示名及 Personal Team。提交中只有团队标识，不包含证书、私钥或描述文件。其他开发者需要在本机选择自己的签名团队；模拟器不要求真机签名。

## 验证环境与结果

- Xcode 26.3，iPhone 17 Pro 模拟器。Xcode 运行目标标为 iOS 26.3.1，Simulator 窗口标为 iOS 26.3。
- Debug 模拟器构建通过。构建日志中的 App Intents 元数据跳过提示符合本阶段未接入 Siri 的范围。
- 总览、任务栏、日历、人员均可点击，页面标题和选中标记随之变化。
- 在任务栏打开创建卡片，输入“确认包装报价”，键盘出现后输入框与关闭按钮可见；关闭后任务栏仍选中。
- 在日历打开创建卡片，输入框为空，关闭后日历仍选中。预览输入没有持久化，也没有实际新增任务。
- 修复 Date 格式受系统语言覆盖的问题，模拟器实际显示“2026年9月20日”。
- 默认字体下，浅色总览、日历、人员及创建卡片完成截图检查；深色总览的标题、内容、导航和添加按钮完成截图检查。
- `git diff --check` 通过。

构建方式（在仓库根目录运行，设备 ID 按本机模拟器调整）：

```bash
xcodebuild -project manager.xcodeproj -scheme manager \
  -configuration Debug \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO build
```

## 尚未通过的检查

- 自动化滚动/拖拽没有稳定触发模拟器手势；需要手工验证总览下方“即将到期”“最近任务栏”可达，以及底部导航和折叠标题保持正常。
- 大字体设置尝试期间，屏幕捕获工具出现 ScreenCaptureKit 错误，未完成大字体的视觉验收。代码对辅助功能字号采用单列象限布局，但不据此宣称实测通过。已恢复默认字体和浅色模式。
- 真机安装、签名闭环、断开数据线后启动，以及同事审核未完成。
- 未实施任务持久化、月/周日历、提醒、附件、AI 或 Siri，未将其标为已交付。

## 用户试用动作

1. 依次点击四个页面，确认布局和入口顺序符合预期。
2. 从任意页面点“＋”，输入文字，再关闭；应回到原页面，文字不保存。
3. 滚动总览到最底部，确认所有区块可见、底部导航始终可点。

模拟器导航通过不代表完整 M1 已完成，真机验收门槛保留。

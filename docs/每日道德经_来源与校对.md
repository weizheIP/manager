# 每日道德经：原文来源与校对

核对日期：2026-09-20。所据文本：[维基文库《道德經（王弼本）》](https://zh.wikisource.org/wiki/道德經_(王弼本))，华亭张氏原本，晋王弼注。采用其中已进入公有领域的《老子》原文节选，不采用现代译文或在线生成的古文。

实现位置：`manager/Core/DailyReading.swift`。按设备所在时区的公历日期轮换；同一天保持同一条。原文随 App 提供，展示不联网；用户主动打开“原文来源”中的链接时才访问来源站点。背景沿用本项目绘制的山水，不抓取外部图片。

这不是 81 章全文库，也不是每天生成新原文；当前八条循环。后续扩充必须逐条核对真实来源。

# 次第 V1 PRD 完成度审计

审计日期：2026-09-20

依据：[次第 V1 产品需求文档](次第_V1_PRD.docx) V1.0 功能冻结版，以及仓库中当前代码、自动测试、签名模拟器运行结果和各里程碑验收记录。

## 当前结论

PRD 中的 V1 MUST 已具备对应的数据结构、界面或系统入口。当前代码可以在签名的 iPhone 17 Pro 模拟器中运行，33 个核心测试和静态分析全部通过，通用 iOS arm64 设备目标可以编译。

这些证据证明软件实现已覆盖第一版范围，但尚不能证明 V1 完成。真机安装、真实权限和系统行为、Apple Intelligence、Siri 语音、同事审核与 TestFlight 仍是发布验收门槛。

## 尚需完成的发布验收

1. 在 iPhone 17 Pro、iOS 26.4.2 上完成签名安装、拔线启动、重启和数据保留检查。
2. 真机验证普通通知与强提醒在锁屏、后台、静音、专注模式、重启和时区变化下的实际表现。
3. 用户允许权限后验证 App 内语音输入和录音附件，包括拒绝、停止、音频中断和 60 秒边界。
4. 从系统文件提供器导入 PDF、Office 文档和音频，验证保存、Quick Look 或系统打开及重启保留。
5. 在支持 Apple Intelligence 的 iPhone 上运行 PRD 附录 A，以及缺字段、重名、否定、相对日期和取消确认用例。
6. 用中文对 Siri 验证三个入口，包括解锁、锁屏、同名任务栏、无匹配任务栏和取消路径。
7. 完成长列表性能、新装与升级数据、崩溃恢复、VoiceOver 手势和真机辅助功能显示等集中回归。模拟器深色模式与辅助功能超大字号回归已通过。
8. 由程序员同事完成架构和代码审核，并确认正式开发团队、Bundle ID 与签名归属。
9. 上传 TestFlight，可追溯到明确提交，由测试者实际安装并完成日常真实使用观察。

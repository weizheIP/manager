# 本地任务与提醒开发记录

2026-09-20，分支 `feat/m1-navigation`。此记录接续 M1 导航记录，描述当前实现和已经执行的验证，不代表完整 V1 验收通过。

## 已实现

- 版本化本地 JSON 数据仓库，原子保存；读取损坏或未来版本数据时保留原文件并禁止覆盖。
- 任务栏创建、改名、手动排序、归档、废纸篓恢复；任务可仅填写名称创建，支持编辑、排序、完成确认、归档和恢复。
- 稳定 ID 的任务、步骤、人员、分配关系、DDL、提醒和附件记录；任务/步骤多负责人，每人独立 DDL。
- 步骤排序、软依赖风险提示、循环依赖校验；所有步骤完成不自动完成总任务；仍有未完成步骤时完成总任务需要再次确认。
- 总览今日/未来 7 天、四象限、任务栏、人员负载、月/7 天日历、三类 DDL 筛选、搜索及统一任务详情。
- 普通通知接入 UserNotifications，强提醒接入 AlarmKit。每条 DDL 支持多个独立提醒、分钟/小时/天/周提前量。
- 提醒权限由设置页主动申请；保存、启动和回到前台时串行核对系统调度，完成/归档/删除后撤销提醒。失败、权限缺失和超出当前排队范围的提醒都有可见状态，不将其标为已排定。
- 普通提醒每次只排最近 60 条，其余打开 App 或保存时续排；这一限制明确显示。仅设日期时，以该日当地 09:00 为提醒基准，界面明确提示，DDL 本身仍为日期。

## 验证结果

环境：Xcode 26.3，iPhone 17 Pro 模拟器，iOS 26.3；工程最低版本 iOS 26.2。

- `swift test`：13 项测试通过。覆盖原子保存、拒绝坏数据、稳定 ID、独立 DDL、软依赖/循环、到期只提示、归档搜索、30 天边界、单独恢复、提醒类型/提前量/路由、日期提醒基准和完成/归档/删除后排程移除。
- iOS 模拟器 Debug 构建通过。
- 实际界面创建“验收：重启后仍能看到任务”，强制结束再启动后，从未分类列表可打开该任务，状态/DDL/负责人仍为空。
- 普通通知和 AlarmKit 授权提示均实际出现；允许后设置页均显示“已允许”。最终安装包已检查包含 `NSAlarmKitUsageDescription`。
- 实际界面创建 `Reminder smoke test`，同一总任务 DDL 设置普通和强提醒各一条；编辑为 2026-09-20 12:24 后保存。
- 12:24 模拟器同时显示普通通知横幅（任务名与总任务 DDL）以及系统闹钟的灵动岛展示；已关闭该测试闹钟。不据截图推断实际声音、震动或真机行为。
- List 的滚动辅助操作已触发，能够到达提醒配置下方的负责人、步骤和备注。
- 本轮修正同一负责人出现在不同步骤时的重复滚动 ID，以及从已归档任务栏单独恢复任务时的处理。

## 仍需验证或实现

- 自动化覆盖的是纯数据与提醒计划，不是完整 UI 或系统权限测试；手动拖动排序、完整多人/多步骤 UI 流程、大字体、深色和长内容需要继续验收。
- 通知点击定位、提醒编辑/删除后的系统队列、拒绝权限后恢复、超过队列容量、进程退出/重启及跨时区需要系统回归。
- 真机锁屏、静音、专注模式、闹钟声音/震动尚未验收；模拟器成功不能代替真机验证。
- 附件文件存储、图片、录音、语音输入、自然语言解析预览、Siri、道德经校对原文库仍未交付。
- 数据结构当前是首次发布的 schema 1；拒绝未来版本已测试，实际跨版本迁移尚无历史版本可验证。
- 签名和真实设备闭环、同事审核、TestFlight 内测仍未完成。完整 V1 目标保持进行中。

## 复验

```bash
swift test
xcodebuild -project manager.xcodeproj -scheme manager \
  -configuration Debug \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO build
```

界面入口：任务栏 → 提醒设置；任务编辑 → 更多设置 → 总任务 DDL → 提醒。步骤和个人 DDL 使用同一个提醒编辑器。

系统接口参考：[Apple AlarmKit 示例](https://developer.apple.com/documentation/alarmkit/scheduling-an-alarm-with-alarmkit)、[Apple AlarmKit 介绍](https://developer.apple.com/videos/play/wwdc2025/230/)、[本地通知调度](https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app)。实际编译接口核对了本机 iOS 26.2 SDK。
